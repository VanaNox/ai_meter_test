# AI Шарометр

Статичний односторінковий квіз, готовий до GitHub Pages. Уся логіка тесту працює в браузері; для знеособленої продуктової аналітики підключено Google Analytics 4.

## Що входить

- Два режими після старту: синій light та червоний hard.
- Інтерактивний glassmorphism-Шарометр: стрілка плавно реагує на курсор, а клік показує одну з чотирьох фанових реакцій.
- 60 запитань у двох окремих пулах: по 30 для кожного режиму.
- Одна спроба: випадкові 3 easy, 4 medium і 3 hard із вибраного пулу без повторів.
- Окрема реакція після кожної відповіді та по 5 випадкових заголовків для кожного рівня правильності.
- Чотири фінальні AI-рівні та персональний напрям розвитку.
- Генерація PNG-сертифіката з ім'ям користувача.
- Клавіатурне керування A–D і 1–4.
- Адаптивна верстка та підтримка `prefers-reduced-motion`.
- Google Analytics 4 з подіями воронки тесту та результату.

## Google Analytics 4

Підключено Measurement ID `G-TQ5VEZTJ2P`. Тег не передає ім'я із сертифіката, текст відповідей або інші персональні дані. Також вимкнені Google signals і персоналізація реклами.

| Подія | Коли спрацьовує | Ключові параметри |
| --- | --- | --- |
| `page_view` | Відкриття сторінки | автоматично від GA4 |
| `quiz_start_clicked` | Натискання «Почати тест» | — |
| `quiz_mode_selected` | Вибір light або hard | `quiz_mode` |
| `tutorial_begin` | Старт вибраного тесту | `quiz_mode` |
| `quiz_question_viewed` | Показ кожного питання | номер, ID, рівень, категорія |
| `quiz_question_answered` | Вибір відповіді | номер, рівень, категорія, варіант, бали |
| `quiz_feedback_viewed` | Показ реакції після відповіді | номер, бали |
| `tutorial_complete` | Показ фінального результату | режим, бали, відсоток, AI-рівень, сильна зона, зона росту |
| `quiz_restarted` / `quiz_exited` | Повторна спроба або вихід до завершення | режим, кількість відповідей |
| `certificate_downloaded` | Завантаження PNG-сертифіката | режим, відсоток, AI-рівень |
| `share` | Копіювання результату | метод, режим, відсоток |

Позначте `tutorial_complete` як **Key event** у GA4: **Admin → Events → Mark as key event**. Для аналізу параметрів у звітах зареєструйте потрібні custom dimensions (наприклад `quiz_mode`, `score_percent`, `result_tier`, `question_difficulty`, `question_category`).

## Локальний перегляд

Відкрийте папку в локальному HTTP-сервері. Наприклад:

```powershell
python -m http.server 4173
```

Після цього відкрийте `http://localhost:4173`.

Для відтворюваного набору запитань під час QA додайте параметр `seed`, наприклад:

```text
http://localhost:4173/?seed=qa-demo
```

## Публікація на GitHub Pages

1. Скопіюйте вміст цієї папки в корінь окремого GitHub-репозиторію або в папку, обрану для Pages.
2. У GitHub відкрийте Settings, потім Pages.
3. У секції Build and deployment виберіть Deploy from a branch.
4. Виберіть потрібну гілку та папку `/ (root)`.
5. Збережіть налаштування й дочекайтеся появи публічного URL.

Усі посилання відносні, тому сайт працює і в корені домену, і в GitHub Pages project path.

## Файли

- `index.html` — розмітка трьох станів: старт, квіз і результат.
- `styles.css` — дизайн, адаптивність, друк і доступність.
- `questions.js` — 30 складніших запитань hard-режиму, бали та реакції.
- `light-questions.js` — 30 легших і більш жартівливих запитань.
- `app.js` — випадкова вибірка, навігація, підрахунок і сертифікат.
- `.nojekyll` — вимикає зайву обробку Jekyll.
